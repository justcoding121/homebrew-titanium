# homebrew-titanium

Homebrew tap for the [Titanium Web Proxy](https://github.com/justcoding121/titanium-web-proxy) CLI.

```
brew tap justcoding121/titanium
brew install titanium
```

Formula source of truth also lives in the main repo at `tools/packaging/homebrew/titanium.rb`. After each macOS CLI release, bump `version` + `sha256` (see `bump-formula-shas.sh`).
